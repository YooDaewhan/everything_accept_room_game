# 배포 환경 (이미 구축 완료 — 재구성하지 말 것)

이 프로젝트는 https://everygame.wsestudio.net 에 이미 배포되어 동작 중이다.

구조:
  브라우저 ─ HTTPS ─> everygame.wsestudio.net       ─> nginx 정적 (/var/www/everygame/html)
           └ WSS   ─> everygame.wsestudio.net/gs/   ─> nginx ─> 127.0.0.1:2567 ─> systemd everygame.service

서버: Ubuntu 24.04, 49.247.136.17, root, ~/.ssh/id_ed25519 로 접속.
      1 vCPU / RAM 961MB(가용 약 400MB) / swap 2GB. MySQL 과 auth API(:3000)가 이미 상주 중.
      Node v24 시스템 설치됨. Docker 없음. nginx 1.24 + certbot 자동갱신.
배포: 저장소 루트의 deploy.sh (로컬 빌드 → tar/ssh 업로드 → systemctl restart).
      bash deploy.sh          코드만
      bash deploy.sh --deps   package.json / lock 이 바뀐 경우

같은 서버에 starterpack.wsestudio.net(게임서버 포트 2568, 로컬 vite 5174)이 함께 돌고 있다.
이 프로젝트의 포트 2567 / 5173 을 바꾸면 충돌하거나 nginx proxy_pass 가 깨진다.

# 절대 하지 말 것

- Docker / docker-compose 도입 금지. 계획서(WSE_SURVIVORS_VIBE_CODING_PLAN.md) 6단계는 이 서버에
  맞지 않아 systemd 로 대체했다. RAM 1GB 에 Docker 데몬을 얹으면 순손실이다.
- 서버에서 vite/tsc 빌드 금지. 1 vCPU + 가용 400MB 라 swap 을 긁는다. 빌드는 항상 로컬.
- game-api.wsestudio.net 같은 새 서브도메인 가정 금지. DNS 에 없고 와일드카드도 없다.
  게임 서버는 같은 도메인의 /gs/ 경로다.
- nginx 를 컨테이너화하거나 80/443 을 다른 프로세스가 잡게 하지 말 것. 다른 서비스 4개가 물려 있다.
- 포트 2567 변경 금지(systemd unit 과 nginx proxy_pass 가 물려 있다).
- 서버에 .env 파일 없음. 환경변수는 /etc/systemd/system/everygame.service 의 Environment= 로 주입한다
  (NODE_ENV, PORT, CLIENT_ORIGIN). 새 환경변수가 필요하면 unit 파일 수정 + daemon-reload 가 필요하다고 보고할 것.

# 코드 작성 시 주의점

- 서버는 ESM + tsconfig moduleResolution NodeNext 다. 상대 경로 import 에 반드시 .js 확장자를 붙인다
  (예: import { LobbyRoom } from './rooms/LobbyRoom.js'). 빼면 런타임에서 죽는다.
- VITE_GAME_SERVER_URL 은 빌드 타임에 번들에 박힌다. 런타임 변경 불가.
  로컬 dev = http://localhost:2567, 운영 = https://everygame.wsestudio.net/gs.
- nginx 의 /gs/ 프록시는 proxy_pass 끝의 슬래시로 /gs 접두사를 떼어낸다.
  따라서 서버 코드는 접두사를 몰라도 되고, 알아서도 안 된다. 서버에 basePath 같은 걸 추가하지 말 것.
- 방 코드는 this.roomId = code (6자리) 로 덮어쓰는 구조다. 참가는 client.joinById(code) 로 한다.
  방 이름은 'survivors'. 이 규칙을 바꾸면 초대 코드 기능 전체가 깨진다.
- 성능 예산: 서버 20 tick / patch rate 설정값 유지. 1 vCPU 공유 환경이라 몬스터 수나 tick 을 올리면
  다른 서비스(MySQL, auth)까지 영향을 받는다. 현재 게임 서버 RSS 는 45MB.
- 클라이언트 번들이 이미 1.79MB(gzip 499KB)다. Phaser 4 전체가 들어있다.
  새 라이브러리를 추가하기 전에 정말 필요한지 따져라.

# 알려진 이슈 (고치면 좋은 것)

1. npm ci 시 esbuild / msgpackr-extract 의 install script 가 npm 정책상 실행되지 않는다.
   현재 동작에는 영향 없다(msgpackr 는 JS 폴백). 로그에 경고가 떠도 무시해도 된다.
2. 재접속 유예가 없다. onLeave 에서 플레이어를 즉시 제거한다 — 계획서대로 MVP 이후 과제.
